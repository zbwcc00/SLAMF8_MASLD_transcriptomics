# Figure 1 Source Data

`Source_Data_Figure1_single_cell_atlas.tsv.gz` contains the cell-level records used to render the cross-cohort single-cell atlas.

- 38,434 retained singlet cells are included across three cohorts and two lineage-restricted objects.
- Columns include dataset, lineage, cell identifier, UMAP coordinates, original subtype, harmonized broad annotation, donor/sample identifiers and available disease metadata.
- Counts are GSE344087: myeloid 7,486 and HSC/fibroblast 643; GSE298719: myeloid 7,719 and HSC/fibroblast 6,813; GSE212837: myeloid 9,810 and HSC/fibroblast 5,963.
- UMAP coordinates represent transcriptional embedding coordinates and are not spatial coordinates. Cells are visualization units; inferential analyses use the patient/sample units described in the Methods.
