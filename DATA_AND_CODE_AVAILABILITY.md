# Data and Code Availability

## Manuscript-ready text

All primary transcriptomic data analyzed in this study are publicly available from NCBI Gene Expression Omnibus under accessions GSE344087, GSE298719, GSE212837, GSE162694, GSE130970, GSE167523, GSE126848, GSE193066, GSE281797, GSE83452 and GSE192741. The processed figure-level Source Data, Supplementary Tables S1–S14, accession metadata and analysis scripts are archived in Zenodo at https://doi.org/10.5281/zenodo.23042100 and mirrored in the versioned GitHub release at https://github.com/zbwcc00/SLAMF8_MASLD_transcriptomics/releases/tag/v1.0.0. No new primary sequencing data were generated. Third-party raw data are not redistributed in this repository.

The analysis code supporting this study is available in Zenodo at https://doi.org/10.5281/zenodo.23042100 and GitHub at https://github.com/zbwcc00/SLAMF8_MASLD_transcriptomics/releases/tag/v1.0.0. The archived release contains pinned Python dependencies, an R package-version inventory, script execution order, data provenance records and SHA-256 checksums.
